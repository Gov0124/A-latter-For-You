# A little note

A small static apology letter for Chinnu, with the song `Baby O Baby.mp3`.

## Publish with GitHub Pages

1. Create a GitHub repository and push the files in this folder to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select branch `main` and folder `/ (root)`.
4. Save. GitHub Pages will publish the root `index.html` and its sibling MP3 file.

Keep `index.html` and `Baby O Baby.mp3` together in the repository root. The song begins when the visitor presses **Open your letter**.
